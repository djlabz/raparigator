# T-19 Virada para API e Remoção de Mocks Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Concluir a migração da Fase 1 removendo todos os mocks locais (`mock-data.ts`, `mock-users.ts`), simplificando adaptadores para operar exclusivamente contra a API, configurando o Playwright com `globalSetup` para subir/assegurar API + Postgres + seeds, e virando a suíte de testes E2E para rodar 100% contra a API.

**Architecture:** O frontend Next.js 16 deixa de ter dual-mode e passa a consumir puramente o contrato oRPC da API (`apps/api`) e o better-auth para sessões e autenticação. As sementes do banco de dados na API garantem os fixtures necessários para todos os fluxos (anúncios, conversas, mensagens, convites de avaliação e usuários). O Playwright inicializa e valida a disponibilidade da API via `globalSetup` e roda a suíte de 71 testes diretamente contra a API.

**Tech Stack:** Next.js 16 (App Router), React 19, TypeScript, oRPC, better-auth, Drizzle ORM, Postgres 17, MinIO, Playwright, GitHub Actions.

## Global Constraints

- Proibido reintroduzir intermediação de serviço em schema, endpoint, tabela, tipo ou copy (ADR-001..006).
- Imports com `@/` dentro de `apps/web`.
- Não escrever comentários no código (`AGENTS.md` e `GEMINI.md`).
- Textos de UI em português (PT-BR).
- `grep -r mock-data apps/web` não pode retornar nada ao final.
- `npm run check`, `npm run test` e `PORT=3100 npm run test:e2e` devem terminar 100% verdes.
