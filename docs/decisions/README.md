# Decisoes

Este diretorio registra decisoes duraveis do projeto para evitar rediscutir escolhas ja aceitas ou rejeitadas.

## Indice

| ADR | Status | Titulo |
|---|---|---|
| [0001](./0001-context-architecture.md) | Aceita | Arquitetura minima de contexto para agentes |

## Regras

- Crie ADR quando a decisao afetar stack, arquitetura, seguranca, workflow repetitivo, contexto de agentes ou dependencias.
- Nao use ADR para tarefas pequenas, bugs locais ou preferencias pessoais.
- Registre opcoes rejeitadas explicitamente quando isso evitar re-sugestoes futuras.
- Nao edite substancialmente uma ADR aceita; crie nova ADR e marque a anterior como superseded quando necessario.
